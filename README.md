## Paper

This repository contains the official implementation of **Gamma-Guard: Lightweight Residual Adapters for Robust Guardrails in Large Language Models**, published at **EMNLP 2025 (Main Conference)**.

Gamma-Guard introduces lightweight residual adapters to improve the robustness of LLM-based guardrails against adversarial inputs.

📄 [Paper](https://aclanthology.org/2025.emnlp-main.614/) | [PDF](https://aclanthology.org/2025.emnlp-main.614.pdf)
